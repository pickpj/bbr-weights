# bbr-weights  

Modified version of big-b-router for weighted ALPR avoidance routing in Osmand. This add's some complexity and slightly slower route calculations, but with the benefit of enabling more routing options. One can make tradeoffs between speed and privacy. It can also enable routing to locations that are otherwise unreachable in big-b-router.    

<img width="1634" height="716" alt="gates" src="https://github.com/user-attachments/assets/dd665f65-e2ee-49a2-b1b1-4f5343079eac" />  

This version of bbr edits in gates along where ALPRs are located. A routing.xml file is then modified to add time penalties to crossing said gates.   

The time penalty for crossing an ALPR can be adjusted within the app through the navigation settings's > route parameters.
